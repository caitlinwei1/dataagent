| 选表错误不会补召回，同一条错 SQL 重写 10 次 | B4 | **流程已修**：沿外键补表，3~4 次结束。**口径没修**：类目层级仍写错，结果为空 |

剩下的三类错误（自己加条件、类目层级、报告和 Python 汇总写错）执行时都不会报错，所以重试和校验都抓不到，只能靠确定性的结果校验（本表第 3 条）和流式接口也跑数字溯源。这让第 3 条的优先级比之前更高。

## 只建议补的三件事（按性价比）

1. **合并两个分支**（#2）：几乎零成本，消除"GitHub 上看不到"的硬伤。
2. **跑完 320 题 dev + holdout 一次**（#1）：约 16 元、3 小时，换来所有核心指标的全量数字。
3. **薄版结果校验器**（#3）：约半天，让简历最具体的一句话有代码可指；不补就改说法。

其余都用"改说法 + 主动讲局限"处理。面试官更在意你知道边界在哪，而不是每条都做满。
