→ **归因分析降级为单维度：仅按 `reason_code` 展开**，并在报告中明确标注该约束。

## 3. 数据分析过程

### 3.1 SQL 查询逻辑（已执行）

#### ▸ 2026年2月成功退款汇总（step_1）
```sql
SELECT 
  reason_code,
  SUM(refund_amount) AS refund_amount_sum
FROM trd_refund
WHERE 
  refund_status = 'SUCCESS'
  AND create_time >= '2026-02-01' 
  AND create_time < '2026-03-01'
GROUP BY reason_code;
```

#### ▸ 2026年1月成功退款汇总（step_2）
```sql
SELECT 
  reason_code,
  SUM(refund_amount) AS refund_amount_sum
FROM trd_refund
WHERE 
  refund_status = 'SUCCESS'
  AND create_time >= '2026-01-01' 
  AND create_time < '2026-02-01'
GROUP BY reason_code;
```

### 3.2 Python 归因计算逻辑（step_3）

- 合并两月数据，对齐 `reason_code`；
- 计算每项的：
  - 环比变化额 = 2月值 − 1月值  
  - 环比增长率 = (2月值 − 1月值) / 1月值（分母为0时标记为 `N/A`）  
  - 2月占比 = 2月值 / 2月总额  
- 排序识别 Top3 增幅/降幅原因；
- 验证总额一致性（确保无数据截断或精度丢失）。

> 🔍 **校验发现**：原始 step_3 输出中误称“缺少1月数据”，实则 step_2 已完整返回6条记录，总和为 ¥135,390.30。本报告采用准确计算结果。
