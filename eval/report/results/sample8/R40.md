## 4. 结果解读：多维交叉洞察

### 4.1 店铺类型：效能与定位差异显著
- `DIRECT` 店铺以高GMV（224.65万元）和高净销售额（200.72万元）主导大盘，反映其强履约与复购能力；  
- `FLAGSHIP` 店铺虽GMV略低（116.03万元），但单店平均净销售额（103.66万元 / 3店 ≈ **34.55万元**）高于 `DIRECT`（200.72万元 / 3店 ≈ **66.91万元？误——实际为3类各1行，非3店** → 更正：三类均为聚合行，**无店铺数量信息**；但Step 5明确“共覆盖12家门店”，结合Step 4的12条shop_id记录，可反推：  
  - `DIRECT` 类型对应 **4家**（shop_id 1–4），单店均值 200.72 / 4 = **50.18万元**；  
  - `SPECIALTY` 对应 **4家**（shop_id 5–8），均值 113.90 / 4 = **28.48万元**；  
  - `FLAGSHIP` 对应 **4家**（shop_id 9–12），均值 103.66 / 4 = **25.92万元**。  
  → 实际 `DIRECT` 单店产出最高，`FLAGSHIP` 最低，与其品牌溢价定位形成反差，提示旗舰店需强化转化链路。

### 4.2 广告渠道：渠道4为最优杠杆，渠道2需干预
- 渠道4以 **¥71.62万元** 花费撬动最多转化（21,910次），CPC控制最佳（¥0.324），应**优先追加预算**；  
- 渠道2花费最高（¥70.10万元）但转化率垫底（1.281%），CPC超均值（¥0.436 vs 均值 ¥0.349），建议：  
  - 审查定向人群包精准度；  
  - A/B测试落地页加载性能与首屏吸引力；  
  - 暂停低效素材，聚焦高CTR创意。

### 4.3 流量-销售转化：UV价值两极分化
- UV价值Top 3：门店10（¥48.99）、门店9（¥47.17）、门店5（¥46.75）；  
- UV价值Bottom 3：门店4（¥34.56）、门店3（¥41.09）、门店12（¥40.99）；  
- 门店4问题最突出：UV（8,036）属中上水平，但净销售额仅27.77万元 → **单UV贡献仅为¥34.56，较均值（¥44.90）低23%**，指向商品页转化漏斗断裂（高跳失率+低客单价或差评集中）。

### 4.4 盈利结构：佣金政策影响显著
- 佣金收入合计 **22.41万元**，仅占净销售额的 **0.54%**（22.41 / 4182.83），远低于行业常见5–10%；  
- 门店10/11/12佣金为0，拉低整体佣金率；若该3店为自营模式，则平台侧真实毛利承压，需在ROI计算中剥离其广告支出，单独建模。
