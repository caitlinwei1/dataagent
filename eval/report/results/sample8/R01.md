因此，本报告严格基于**可验证、可追溯的平台与店铺粒度数据**开展归因，拒绝推测性填充。

## 3. 数据分析过程

### 3.1 数据提取逻辑（SQL）

#### 平台维度汇总（step_1）
```sql
SELECT 
  p.name AS platform_name,
  DATE_FORMAT(s.stat_date, '%Y-%m') AS month,
  SUM(s.gmv) AS total_gmv
FROM trd_daily_shop_sales s
JOIN dim_shop sh ON s.shop_id = sh.id
JOIN dim_region r ON sh.region_id = r.id
JOIN dim_platform p ON sh.platform_id = p.id
WHERE 
  r.big_region = '华东'
  AND s.stat_date >= '2026-01-01' AND s.stat_date < '2026-03-01'
GROUP BY p.name, DATE_FORMAT(s.stat_date, '%Y-%m')
ORDER BY p.name, month;
```

#### 店铺维度汇总（step_2）
```sql
SELECT 
  sh.shop_name,
  DATE_FORMAT(s.stat_date, '%Y-%m') AS year_month,
  SUM(s.gmv) AS gmv
FROM trd_daily_shop_sales s
JOIN dim_shop sh ON s.shop_id = sh.id
JOIN dim_region r ON sh.region_id = r.id
WHERE 
  r.big_region = '华东'
  AND s.stat_date >= '2026-01-01' AND s.stat_date < '2026-03-01'
GROUP BY sh.shop_name, DATE_FORMAT(s.stat_date, '%Y-%m')
ORDER BY sh.shop_name, year_month;
```

## 4. 结果解读

### 4.1 平台维度：三平台同步失速，无结构性亮点
- **天猫**（占比56.9%）仍是最大单一渠道，但贡献了超一半的负向增量（54.6%），主因是旗下3家天猫系店铺集体下滑；
- **抖音**与**自营商城**降幅相近（-49.5% vs -44.4%），且二者变化量之和（-171,409.36）占总下降的45.4%，表明非天猫渠道同样承压；
- **无平台逆势增长**：排除“某平台抢夺其他平台份额”的假说，指向**共同外部因素**。

### 4.2 店铺维度：头部店铺全面塌方，旗舰店拖累最重
- “天猫旗舰店”单店减少8640万元，为**最大负向贡献源**（22.9%），其降幅（53.1%）亦为最高；
- “抖音官方直播间”与“自营商城总店”变化量完全等同于其所属平台变化量 → 说明这两平台**仅由单一店铺构成**，无其他店铺分摊影响；
- 所有店铺降幅集中在40.5%–53.1%，标准差仅5.2%，印证**高度同质化波动**。

### 4.3 一级类目维度：技术性不可归因（明确声明）
- Schema 中无 `trd_daily_shop_sales.category_id` 字段；
- `prd_category` 表无 `level1_name` 字段，且 `id` 未在任何销售表中作为外键出现；
- **强行归因将导致数据幻觉**，故本报告不提供任何类目相关推测。
